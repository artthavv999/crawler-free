    Features

    Four ways to read a site, two ways to repeat it.

    The page's text, without the clutter

    Menus, cookie banners, sidebars and other page furniture are removed. What's left comes back as clean Markdown you can read, paste into notes, or hand to an AI.

    • Headings, lists and code blocks come through as Markdown
    • Pages that show no text without JavaScript can't be read for now (see the FAQ)
    • Answers are cached for 1 hour
    POST /v2/scrape
{ "url": "https://example.com",
  "formats": ["markdown"] }

→ data.markdown

    Every link on the page

    A list of the links on the page, one per line, ready to paste into a spreadsheet or feed into your own crawler.

    • Read from the page itself
    • Shown together with the page's text, in its own tab
    • Same limit as a page read: 20 a minute, 1,000 a day
    POST /v2/scrape
{ "url": "https://example.com",
  "formats": ["links"] }

→ data.links

    Just the facts you name

    Type the facts you want, such as title, price. An AI model on Cloudflare reads the page and answers with neat JSON, one value per fact.

    • 20 fresh look-ups per 24 hours; cached answers don't count
    • Runs on a free AI budget shared by everyone
    • Every fact you name comes back as a key
    POST /v2/scrape
{ "url": "https://example.com",
  "formats": [{ "type": "json",
    "schema": { "type": "object",
      "properties": {
        "title": { "type": "string" } } } }] }

→ data.json

    A whole website, page by page

    Start from one address and Crawler Free follows the site's sitemap and links, reading each page politely and waiting between requests.

    • Up to 100 pages, up to 3 links deep
    • Stays on the same site, under the starting address's path
    • 5 whole-website reads per 24 hours; results kept for 24 hours
    POST /v2/crawl
{ "url": "https://example.com",
  "limit": 10 }

GET  /v2/crawl/{id}
→ status, completed, total, data[]

    Save it once, re-run it in one step

    Save an address and what you want from it. After that, press Run, open its link in any browser, or paste one command into a terminal.

    • Works for page text, links and facts
    • Keeps only the address and settings, never page content
    • Deleted after 30 days without a run
    # PowerShell
irm https://crawler-free.crawler-free.workers.dev/run/<id>

→ the answer, as plain text

    The same API, from your code

    Crawler Free answers Firecrawl's v2 requests for scrape and crawl, so the official Firecrawl JavaScript SDK works with it. No key needed.

    • Errors come back as { success: false, code, error }
    • Unsupported options are ignored and listed in warning
    • Source code on GitHub, MIT licensed
    See examples 
    import Firecrawl from "@mendable/firecrawl-js";

const app = new Firecrawl({
  apiKey: "fc-keyless",
  apiUrl: "https://crawler-free.crawler-free.workers.dev",
});
const page = await app.scrape("https://example.com");

    How it works

    Three steps, no account.

    1. 01

      Paste an address

      Any public web page. Choose its text, its links or specific facts, or the whole website and how many pages.

    2. 02

      It reads politely

      It checks the site's robots.txt first, refuses private network addresses, and tells the site who it is. It never gets around logins or bot protection.

    3. 03

      Take the result

      Copy it, download it, or save it as a one-click setup you can run again from the page, a link, or a terminal.

    Terminal

    Or type one command.

    The crawler-free command does everything this page does and saves the results as files. It needs no account, no key and no setup. Pick the tab that matches your computer.

    • Type crawler-free on its own for a guided menu that asks what to do
    • Results go into a crawler-free-output folder, and the full path is printed; a file is never replaced without asking
    • If something fails, crawler-free doctor checks your setup and the connection, and says what to fix

    No package manager? Each release also has the program to download by hand. That's for advanced users: check the download is genuine before you run it, and never switch off your computer's security protection to run it.

    Step by step in the guide

    npx crawler-free scrape https://example.com

    API

    Use it from code.

    The same requests this page makes, from any language. There's no key and no sign-up, and the same free limits apply.

    All endpoints in the README

    curl -X POST https://crawler-free.crawler-free.workers.dev/v2/scrape \
  -H "content-type: application/json" \
  -d '{"url":"https://example.com","formats":["markdown","links"]}'
    const res = await fetch("https://crawler-free.crawler-free.workers.dev/v2/scrape", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ url: "https://example.com", formats: ["markdown", "links"] }),
});
const { data } = await res.json();
console.log(data.markdown);
    import requests

res = requests.post(
    "https://crawler-free.crawler-free.workers.dev/v2/scrape",
    json={"url": "https://example.com", "formats": ["markdown", "links"]},
    timeout=60,
)
print(res.json()["data"]["markdown"])

    FAQ

    Questions.

    Yes, it's free. There's no sign-up, no key and no payment. It runs on Cloudflare's free tier, so every connection gets the same fair-use limits.

    Per connection (one IPv4 address, or one IPv6 /64): 20 page reads a minute and 1,000 a day, plus 20 fact look-ups, 5 whole-website reads and 20 new saved setups per 24 hours. Your whole network shares 60 fact look-ups and 10 whole-website reads a day. Everyone together shares 15,000 page reads and 2,500 crawled pages a day, reset at 00:00 UTC. When you hit a limit, the message says how long to wait.

    Only what a site allows. It obeys each site's robots.txt and never gets around logins, paywalls or bot protection; a blocked page returns an error instead. Private and local network addresses are refused.

    Opening pages in a browser is switched off on this service for now (since 20 October 2026, for a security review), so a page that shows no text without JavaScript returns an error instead. Most pages put their text in the HTML and read normally. When it's back on, such pages are opened in Cloudflare's Browser Run, which is shared and has a small daily budget.

    Answers are cached for 1 hour. Whole-website results are deleted after 24 hours. A saved setup keeps only the address and settings, and is deleted after 30 days without a run. Your list of saved setups lives in this browser.

    Disallow CrawlerFree in your robots.txt, or open an issue on GitHub.
